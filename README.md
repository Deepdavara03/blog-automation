# Blog-automation
# 🤖 AI Blog Posting Agent

An end-to-end **AI-powered blog automation workflow built with n8n** that automates the complete content publishing process—from topic research and content generation to image creation and WordPress publishing.

The system integrates **Google Sheets, Tavily, NewsAPI, AI models, and WordPress** to research topics, collect and enrich information, generate SEO-friendly blog posts, create relevant cover images, process metadata, validate content, and automatically publish posts to WordPress.

### 🚀 Features

* 🔍 **Automated Topic Research** using Tavily and NewsAPI
* ✍️ **AI-Powered Blog Generation** with SEO-friendly structure and content
* 🖼️ **AI Cover Image Generation** for blog posts
* 📊 **Google Sheets Integration** for topic and workflow management
* 📝 **Metadata Processing** for titles, descriptions, tags, and categories
* ✅ **Content Validation** before publication
* 🌐 **Automated WordPress Publishing**
* 📌 **Publication Tracking** to monitor the status of generated posts
* ⚡ **End-to-End Automation** using n8n

### 🛠️ Tech Stack

**n8n · AI/LLMs · Tavily · NewsAPI · Google Sheets · WordPress · SEO · AI Image Generation**

### 🔄 Workflow

**Topic → Research → Content Enrichment → AI Blog Generation → SEO & Metadata → Image Generation → Validation → WordPress Publishing → Tracking**

The goal of this project is to demonstrate how **AI agents and workflow automation can be combined to build a scalable, end-to-end content publishing system with minimal manual intervention.**
